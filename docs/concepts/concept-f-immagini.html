Relay

in corso · 2026 · in vetrina

Terminale nativo per macOS pensato per far girare molti coding agent in parallelo, con lo stato di ogni agente letto dagli hook.

Lavoro con cinque o sei sessioni di Claude Code e Codex aperte insieme, su progetti diversi. In un terminale normale, capire quale agente aspetta una risposta vuol dire passare scheda per scheda.

Come funziona

Lo stato di ogni agente (in corso, in attesa, errore, finito) arriva dagli hook di Claude Code e Codex, non dal parsing dell'output.
