VoidScanner is a platform for tracking and analyzing tokens in the Solana ecosystem. Token archive with search and filters from Pump.fun, Raydium and Bonk, automatic data enrichment from multiple APIs, custom lists and watchlists, blacklist and saveable filter presets.

Twitter/X integration: account monitoring, optimized batch scraping via TwitterAPI.io, automatic media download (photos, videos), periodic follower and profile snapshots. Stack: Laravel 11 + PostgreSQL + Redis (backend), Alpine.js + Blade + Tailwind CSS (frontend), FastAPI Python for Twitter scraper.
