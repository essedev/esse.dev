VoidScanner è una piattaforma per tracciare e analizzare token nell'ecosistema Solana. Archivio token con ricerca e filtri da Pump.fun, Raydium e Bonk, arricchimento automatico dati da API multiple, liste personalizzate e watchlist, blacklist e preset filtri salvabili.

Integrazione Twitter/X: monitoraggio account, scraping batch ottimizzato via TwitterAPI.io, download automatico media (foto, video), snapshot periodici follower e profili. Stack: Laravel 11 + PostgreSQL + Redis (backend), Alpine.js + Blade + Tailwind CSS (frontend), FastAPI Python per Twitter scraper.
