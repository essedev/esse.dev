The starting point I used in 2025 for Next.js projects: authentication with Better Auth, three-tier roles, Drizzle on PostgreSQL, transactional email and deploys on Cloudflare Workers. The structure and docs were designed for a coding agent, so it could work on it right away without guessing the conventions.

Today I start from the official init commands and put the conventions in an instructions file for the agent, but the idea started here.
